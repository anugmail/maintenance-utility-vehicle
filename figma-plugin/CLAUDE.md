# figma-plugin — เงื่อนไขการทำงาน

รีโปของปลั๊กอิน Figma งานบำรุงรักษาตามวาระ · แยกจากรีโปงานซ่อม Maintenance-Request-Form และรีโปเว็บต้นแบบ Maintanance (Next.js) — ไม่แก้ไฟล์ในสองรีโปนั้นจากงานนี้

## 🔴 เงื่อนไขบังคับ

1. **`plugins/*/code.js` เป็นไฟล์ประกอบ** แก้ที่ไฟล์ต้นทางแล้ว `npm run build` · คอมมิต `code.js` คู่กับไฟล์ต้นทางเสมอ
2. **`base/` อ่านอย่างเดียว** (สำเนางานพี่นุ) ห้ามแก้ในนั้น · จอที่ต้องต่างจากฐานให้ทับในไฟล์ Feature (`features/<id>.js` · `screens/H:`) · อัปเดตฐานด้วย `npm run sync-base` เท่านั้น แล้วอัปเดต `base/SOURCE.json` (สคริปต์ทำให้)
3. **ห้ามเปลี่ยน `id` ใน manifest** ของปลั๊กอินที่ใช้อยู่ (clientStorage และ pluginData ผูกกับ id) · ปลั๊กอินใหม่ใช้ id ใหม่
4. **ลายเซ็นจอ** (`sig.js` · `MF_DEPHASH`) คือสิ่งที่แท็บ "อัปเดต / ลบ" ใช้ดูว่าจอไหนเปลี่ยน ⇒ อะไรที่ทำให้หน้าตาจอเปลี่ยนต้องอยู่ในลายเซ็น (`npm test` ตรวจ)
5. **รหัสจอใน `features/*.js` ต้องตรงหัวข้อ 3 ของเอกสาร `docs/features/4x-*.md`** แก้รหัสจอ → แก้เอกสารด้วย · ย้ายฐานแล้วไล่รหัสที่ความหมายเปลี่ยน (`docs/notes/MERGE-NOTES.md` ข้อ 3)
6. **ดัมป์ไลบรารี Figma ของ PEA ห้ามเข้า git** (`out/` `figma-dump/` อยู่ใน .gitignore) · ใหญ่ (หลายร้อย MB) และเป็นของ PEA — ไม่เก็บแม้รีโปเป็น private
7. **ภาษา:** ข้อความบนจอภาษาไทย · ใช้ "ยานพาหนะ" แทน "รถ" (ยกเว้นข้อมูลจาก API) · สะกด "ไฮดรอลิก" · ไม่มีอีโมจิบนจอ

## ตรวจก่อนบอกว่าเสร็จ

```bash
npm run build
npm run test:all      # ต้องไม่มีคำเตือนเพิ่มจากก่อนแก้ (19 พ.ย. 2569 ฐาน: หน้าจอ 340 · คำเตือน 182 จาก R19 แถบ Header ของตัวจำลอง)
```

แล้วเปิดในไฟล์ Figma จริงอย่างน้อย 1 Feature (Desktop + Mobile)
